# Reporting security concerns

Please report suspected exploitable vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/theevildarkmage-hue/Civitai-Artist-Discovery/security/advisories/new).
Private reporting is enabled for this repository. Reports go to the repository
maintainer; there is no automatic fix or guaranteed response-time commitment.

Include the affected version/platform, expected and observed behavior, likely
impact, and the minimum safe reproduction using synthetic data. Do not send
passwords, OAuth/session/refresh tokens, API keys, private databases, backup
archives, personal records or unredacted logs. Do not test other users or generate
attack traffic against the hosted Community service.

Use ordinary GitHub Issues for general support, non-sensitive bugs and sanitized
maintenance tracking. Avoid posting exploit instructions or sensitive deployment
diagnostics publicly while a suspected vulnerability is under investigation.

Once a vulnerability has been assessed and a correction is available, coordinate
a public summary explaining impact, affected/fixed versions and update guidance.
Keep unnecessary exploit detail and private records out of that summary. Existing
public issue history cannot be made private by closing an issue.

This reporting policy does not change application authentication, Community
access, release channels, or the separate stable 2.2.1 installation. Current
accepted/deferred decisions are in the [audit tracker](docs/3.0-audit-tracker.md).
