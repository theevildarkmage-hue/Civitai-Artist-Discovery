# Unreleased 3.0 Community Beta preparation

Status: local development candidate, version 3.0.0-dev. No release is published.

Production Community is default-off. An approved endpoint and explicit user opt-in
are required before the Community Beta tab can be used. Disabled/read-only service
states preserve personal galleries; server policy remains authoritative. Public
submissions are blocked from release until moderation and hosted validation close.

The Windows package now physically excludes development identity/fixture modules,
retains the Test Lab in development source and uses the portable data/ directory
required by the existing updater. No existing SQLite schema migration is introduced.
Opt-in preferences use a separate small file and do not overwrite existing settings.

Security validation uses actual local Deno/PostgREST/PostgreSQL plus explicit public
metadata snapshots and simulated test identities. This is not a claim of hosted
Supabase validation or authentication as the ten public creators.

Stable 2.2.1 updater behavior is unchanged. A source branch push does not notify
users. A planned 3.0.0-beta.1 prerelease would require manual installation by stable
users; an approved future stable application update could offer optional Community
participation after all public-write blockers are closed. No tag is created here.

See [readiness and distribution](3.0-beta-readiness.md) and
[staging recovery procedure](3.0-staging-runbook.md) before considering a release.
