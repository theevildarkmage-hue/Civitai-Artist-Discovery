# Owner artwork key proposal retired

The owner approved anonymous retrievability as the artwork eligibility boundary.
No owner-held MediaRead key is needed or requested. The proposal and enrollment
helpers were removed before any key was created or deployed by this work.

The identity-only production entry uses only anonymous public image/post requests.
It never calls Civitai /me, UserInfo, or authenticated artwork detail routes.
Numeric uploader identity comes from the public post, cross-checked against the
exact image lookup. A link-accessible unlisted artwork may be recommended. Private
or unavailable artwork that cannot be retrieved anonymously is ineligible.

See [the implementation and rollout runbook](3.0-identity-only-authentication.md).
Existing deployed clients are not changed by this local source preparation.
