# Linux beta source installation and update

## Beta authenticated activity notice

Discovery 3.0 Beta automatically records your verified Civitai account ID, public
username, first-seen and last-seen timestamps, app version, and platform in its
private Supabase registry after server-side identity verification. This supports
beta usage and compatibility monitoring. Activity updates occur at most once every
12 hours. The registry stores no OAuth tokens or browsing history, is not publicly
searchable, and does not grant Community access. To request deletion, contact the
maintainer through [GitHub Issues](https://github.com/theevildarkmage-hue/Civitai-Artist-Discovery/issues)
for general support. Do not post tokens, account details or sensitive deletion/security
requests publicly. A private channel requires owner approval before tester distribution.
Later authenticated use can recreate a deleted registry entry.


Execution status on 2026-10-23: **not verified on Linux; application testing explicitly waived by the owner**. The available Ubuntu WSL
distribution cannot start: `HCS_E_HYPERV_NOT_INSTALLED`. No Windows virtualization
features, distribution conversion or machine reboot was attempted. Windows unit
tests of the portable source-update logic are not Linux execution evidence.

Use a desktop Linux session with Python 3.12 or later, a supported patched OpenSSL,
Git, a browser, D-Bus and an unlocked Secret Service provider such as GNOME Keyring.
The requirements include keyring on Linux. A headless/plaintext keyring is not a
supported OAuth fallback. This guide is prepared for a later isolated Linux test.

After the beta source/tag has actually been published and approved:

```sh
git clone https://github.com/theevildarkmage-hue/Civitai-Artist-Discovery.git discovery-beta
cd discovery-beta
git checkout --detach v3.0.0-beta.1
git rev-parse HEAD  # compare with the approved release's exact commit
python3 -m venv .venv-beta
.venv-beta/bin/python -m pip install -r requirements.txt
install -d -m 700 "$HOME/.local/share/CivitaiDiscoveryBeta"
export CIVITAI_HISTORY_DATA_DIR="$HOME/.local/share/CivitaiDiscoveryBeta"
.venv-beta/bin/python -B server.py --host 127.0.0.1 --port 8907
```

Do not run this as root. Keep the data directory private and outside the source
checkout. Linux OAuth uses the `CivitaiDiscoveryBeta` Secret Service namespace
scoped to the local data path; the path digest stays local and is never registered
with Supabase. Existing development/stable keyring entries are not imported,
modified or deleted. A new beta profile requires a fresh interactive Civitai login.
The registered callback is `http://localhost:8765/oauth/callback`; changing the app
web port does not change the OAuth callback. Bind only loopback, not a public host.

## Approved source update

Close this beta normally, protect its data, note its current commit, and obtain
the next approved tag and exact immutable commit from the release checklist:

```sh
.venv-beta/bin/python -B scripts/update-beta-source.py --checkout . \
  --tag v3.0.0-beta.2 --commit APPROVED_40_CHARACTER_COMMIT
.venv-beta/bin/python -m pip install -r requirements.txt
```

The tool accepts only the reviewed GitHub remote, fetches one explicit beta tag,
verifies its commit, rejects dirty source and forbidden data in the target tree,
and checks out detached without overwriting ignored files. It never merges,
resets, removes profiles or executes a remote installation script. Inspect changed
dependencies before installing them. A conflict is a stop condition, not a reason
to force checkout. Preserve any custom source elsewhere for review.

Rollback uses the previously recorded compatible beta tag/commit through the same
tool with the data directory unchanged. Do not downgrade local schemas without a
reviewed compatibility statement. Existing update UI remains informational for
source installations; packaged automatic replacement is Windows-only.
