## Architecture and integrity

The identity architecture and Supabase transports are unchanged. Civitai API credentials are stored locally and used with their intended Civitai services; the existing source and frozen transport-isolation suites passed. No authentication or content-control assertion was weakened to pass tests. Optional missing-image handling is restricted to image.get reads and never retries a write. Unknown selection state is distinct from confirmed no-reaction state.

The Daily and Time Machine stores remain separate. The new preview route selects the intended store, including overlap cases with different ratings; it does not copy history to Daily or make arbitrary URLs fetchable. No schema migration was introduced. Preview reads preserve saved records and positions, including on denial, upstream failure and retry. Local cache/tag preparation still makes its ordinary local cache writes.

Real-account acceptance used a separate disposable profile. Only a few noncredential preview records were copied from the existing archive opened read-only. No OAuth files were copied, no original archive was written, and the regular installation was not replaced. Ordinary owner sign-in/session enrollment is normal application activity; no administrative Production schema/configuration/quota action, recommendation submission, reaction toggle, manual credential rotation or deletion occurred.

Production-feed checks prepare new candidates in small batches within the existing four-page scan. This adds bounded metadata reads in exchange for accurate eligible counts; checks do not force unbounded refresh or replace the active cards. Restart selection preserves the fixed reviewed environment rather than accepting arbitrary endpoints.

### Earlier failures retained

Review reproduced two additional reaction races and fixed them before this final build. A previous full gate exposed a diagnostics fixture that set sys.frozen before the required source configuration had been loaded. The same failure reproduced on the unchanged main baseline. The fixture now models actual initialization order; production's missing-configuration failure remains intact. Actual packaged diagnostics were already disabled and denied.

One earlier unavailable-artwork browser wait timed out. Unchanged-baseline and candidate focused reruns passed; failure context was added without relaxing assertions or adding retries. Its exact transient cause was not established. The final clean full run passed that suite. Initial unavailable live-preview samples and their errors remain preserved separately from the successful available-image acceptance.
