## Architecture, security and data integrity

No migrations, schema changes, Production operations, credential rotations, quota
resets, release/tag changes or user-profile migration occurred. The separate Daily
and Time Machine stores remain separate. Preview tests snapshot Time Machine image
and progress tables before/after requests, and verify Time Machine-only images are
not copied into Daily History. Content denials occur before thumbnail fetches.
Unknown IDs and video records cannot turn the still-image route into an arbitrary
URL fetcher. The existing cache continues validating CDN sources.

The all-missing exception is restricted to explicitly optional `image.get` reads,
bounded to one MiB and validated per envelope and batch length. It does not retry
reaction mutations. Signed-identity architecture and Supabase transports were not
changed. Account changes clear ephemeral browser reaction state; nothing new is
persisted. New reaction hydration adds account-authorized reads, and production
update probes may prepare at most the existing four-page scan's candidate IDs in
small batches. This increases metadata work relative to counting unverified IDs;
the scan remains bounded and does not force metadata refresh or replace cards.

Source mode is preserved through the existing fixed stable selector, without an
arbitrary endpoint/configuration option. The restart test releases only its own
managed listener before launching a replacement so the unchanged occupied-port
test guard remains effective. It does not reproduce the exact overlapping-process
shutdown timing; existing instance/restart suites remain separate evidence.

Two test-harness corrections were necessary and their earlier failed runs are
retained: the reaction late-response case initially awaited its deliberately held
request, and the restart scenario initially triggered the occupied-port safety
guard. The final tests avoid that deadlock and release only the test-owned
listener. The banner fixture initially used equal old/new timestamps and was
corrected to represent a genuinely newer recommendation; existing text assertions
now normalize whitespace around the added button. None of these failed runs is
counted as a passing regression.

Not rerun: the entire repository test collection, native PostgreSQL/Edge suites,
full OAuth credential-isolation audit, backup/restore, Linux/WSL, clean packaged
Windows build/acceptance, real provider reaction toggles, live CDN failures or
two-account hosted recommendation arrival. There was no independent agent review
for this change. A source diff review and local tests do not replace those checks.
