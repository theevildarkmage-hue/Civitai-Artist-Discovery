# Permanent Discovery branding ? issue #29

The owner supplied and approved a full logo reference: an italic geometric CIVITAI
wordmark, spaced DISCOVERY lettering, and a sweeping teal/blue D with a four-point
star. This supersedes the earlier exploratory concepts. The header uses its horizontal
lockup; the app icon uses the D and star alone. This is an editable vector reconstruction
of the approved visual direction, not a claim of pixel-identical raster reproduction.

`scripts/brand_artwork.py` is the original path master. It generates six self-contained
SVGs: horizontal and primary lockups in dark/light treatments, a mark, and a favicon.
Lettering is geometric paths, so no external font or proprietary asset is required.
The symbol, trail, star and gradients share canonical geometry with the ICO renderer.
The app icon has a dark inner counter to preserve the white star on light taskbars,
while its outer background remains transparent. Raster frames use 8x supersampling.

The former header loaded a generic icon through a Beta-named URL; stable and beta
builds chose different generic symbols. Both now use the approved permanent identity.
The visible logo contains no version/Beta label. The existing version/environment
indicator remains separate, and no deployment, authentication or navigation policy
changes. The heading has the accessible product name, with no duplicated visible title.
The favicon is SVG with ICO fallback; the same ICO is passed to PyInstaller and the
Windows tray. Shortcut targets inherit the executable's icon when created normally.

ICO output contains 16,20,24,32,40,48,64,96,128,256 pixel frames. The old generator
created multiple images but only passed the largest to Pillow; smaller output was
resampled from it. All explicitly rendered frames are now supplied to the ICO writer.
Historical icon recipes remain for reproduction, but are not selected by release builds.
Only the reviewed `static/discovery-*.svg` source category is newly allowlisted; the
privacy/source gates remain active. Generated ICO/PNG previews stay outside Git.

Targeted source validation: `branding_assets`, `header_polish_browser`,
`navigation_startup_browser`, `stable_source`, `community_access_browser`,
`tray_lifecycle` passed. The new asset suite parses the actual vectors, rejects embedded
raster/font/script dependencies, generates a real ICO, decodes all ten frames, and checks
alpha corners plus the visible white star at every size. Existing header tests retain
all navigation/layout checks at 1440/768/390/320 widths; the name assertion now reflects
the requested accessible graphical wordmark instead of obsolete visible Beta text.
Manual preview covers primary/horizontal lockups and transparent icons on dark/light.

These results verify source rendering and actual icon formats; they do not alone prove
Windows Explorer/taskbar cache refresh or final packaged resources. Frozen-app UI,
executable icon and complete release regression checks follow the rebuild. No profile
migration, database change, settings rewrite or credential access is required for this
branding change. Rollback is the dedicated local branding commit; no data rollback.

The tray tooltip/menu and internal icon name also use permanent Civitai Discovery
wording. They previously hardcoded Beta independently of the actual build channel.
The existing tray lifecycle test checks the new exact name while retaining Open,
Exit, Windows-only import and detached-lifecycle assertions.
