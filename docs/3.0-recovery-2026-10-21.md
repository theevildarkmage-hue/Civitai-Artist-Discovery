**Architecture and integration choice.** Recommend selective ports grouped by concern,
after checkpointing every current 3.0 source artifact on a reviewed recovery branch.
Use a separate integration worktree with new disposable data roots. Never copy either
installation's OAuth credentials or runtime databases into it. A straight fast-forward
of the committed branch would omit all uncommitted 3.0 work; wholesale file replacement
would overwrite the application that exists in the working tree. Large upstream commits
also mix security, presentation and persistence changes, making blind cherry-picks unsafe.

A dry three-way text comparison used temporary files only, without altering either Git
index or source tree. Of 81 upstream paths, 23 also have development changes; six paths
have textual conflicts: `.gitignore` (1 region), `requirements.txt` (1), `server.py` (3),
`static/app.js` (2), `static/ui/api.js` (1), `static/ui/bootstrap.js` (1).
Clean text merges in OAuth, taste, cards and filters still carry semantic risks. Counts
describe a normalized text rehearsal, not a completed or validated Git merge.
