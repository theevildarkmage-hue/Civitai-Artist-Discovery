### Working design decisions

- Preserve the existing feed meanings (including Followed First, which is not followed-only).
  Avoid renaming it Following without changing and testing the behavior deliberately.
- Keep view/feed and date prominent, put model/content refinements in Filters, and display
  density and ranking thresholds in preferences. Do not add a sort menu with no distinct
  backend meaning.
- Time Machine already calls the gallery `card()` factory. Extract this shared behavior
  rather than inventing an additional renderer.
- Introduce modules through a small bootstrap while the legacy page controller remains a
  classic script. Existing tests exercise its global functions, so moving the entire file
  into module scope in one step would obscure behavioral regressions with test failures.
- Server static-file handling and packaging already support nested assets. Git's strict
  source allowlist must explicitly admit the new module and stylesheet directories.

  the original-image fallback to the missing generated preview.
- Added shared skeleton cards while the initial artist response is pending.
- Replaced the filter reload's up-to-eight-second wait with AbortController cancellation.
  Old request cleanup cannot unlock a new request's paging guard. A held-response browser
  test proves the new view appears without waiting for the old response.

  hidden-tag snapshot, preserving unknown versus known-empty states and chunking large

  The shared card builder seeds its tag cache from known decisions; unswept artwork still
  takes the existing verification path. Tests cover no verification request for known
  previews, verification for unknown previews, and no CDN request for a known hidden card.
- Five-run synthetic 50-image median: 70.22 ms for per-image reads versus 1.51 ms for the
  batch. These timings isolate local tag reads, not end-to-end loading or CDN performance.
- Added an independent `main` worktree in sibling `Civitai Desktop Client-v1`, so urgent
  1.x work does not require interrupting the v2 working tree or sharing its local data.
