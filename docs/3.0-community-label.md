# 3.0.2 stable navigation wording — issue #27

The navigation label is Community from initial mount onward, including after the
asynchronous policy/configuration response. Generic read-only and moderation wording
also uses Community. Invitation-specific Beta messages remain for actual invitation
denials, expiration and revocation.

The previous policy callback overwrote Community Gallery with Community Beta whenever
the backend was policy-controlled. That flag is not a reliable deployment-environment
label: packaged Development previews are policy-controlled too. This change only fixes
visible wording. It does not change flags, endpoints, selected environment, invitation
policy, quotas, authentication, database records or API identifiers. The separate
version/environment indicator identifies the actual Community deployment.

Six existing suites passed: `header_polish_browser`, `navigation_startup_browser`,
`community_access_browser`, `community_access_modes_browser`,
`community_filters_browser` and `community_reentry_browser`. The header assertion now
requires the requested exact Community label; earlier layout/access assertions remain.
Final frozen-UI verification follows the complete release rebuild. No data migration
or rollback operation is needed for this wording change.
