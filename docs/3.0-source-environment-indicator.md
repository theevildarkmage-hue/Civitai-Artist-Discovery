# 3.0.2 environment indicator and source notice — PR #57

Reviewed the complete proposed diff at head
`587b926b64a633bec772bfaf0987800cf6c66537` against the synchronized release baseline
and current reliability fixes. The implementation is integrated with adaptations,
not cherry-picked blindly. No unrelated fork features are included.

The source-launch notice has an accessible dismiss button. Dismissal is saved in
browser local storage using separate Production and Development keys; unavailable
storage still permits dismissing the current notice. Keyboard focus returns to the
version after dismissal. The notice remains absent from frozen packages.

The actual configured Community environment is always visible, including in packages.
Version and environment share one colored indicator rather than adding another badge.
Labels say Public Community or Development Community, avoiding an ambiguous extra
Beta label and distinguishing deployment environment from version/channel naming.
The text remains meaningful without color. The existing version span and its exact
version text remain intact for accessibility and existing version consumers.

The proposal conflicted with the new authentication bootstrap import. That import
and its shared auth controller were retained while adding the notice mount. Server
rendering still obtains environment only from validated build configuration; no user
preference, notice dismissal or browser storage value can change service selection.
No database, credential, hosted policy or access-control changes are included.

`stable_source` retains its earlier isolation checks and now exercises Production and
Development labels, combined-indicator uniqueness, dismissal/reload persistence,
environment separation, keyboard focus and storage failure. Existing mobile/desktop
header and navigation regressions also run. These use isolated local source servers
and synthetic identities where applicable, never Production social mutations.
Source screenshots remain in the private test artifacts. Final packaged indicator
acceptance follows the remaining sequential release items and package rebuild.

Local storage is origin-scoped: its saved dismissal does not automatically transfer
to a different hostname, port or browser profile. This affects notice convenience
only; the environment indicator remains visible independently of dismissal.
